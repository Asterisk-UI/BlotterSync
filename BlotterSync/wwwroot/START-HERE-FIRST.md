## 🆘 Troubleshooting

### App won't load
→ Check browser console (F12) for errors
→ Verify you're opening `index-standalone.html`
→ Try a different browser

### Can't login
→ Try demo: username `officer`, password `password123`
→ Or click "Explore Demo"
→ Check browser localStorage isn't disabled

### Data disappeared
→ Check Settings → Reset to Demo
→ Open browser console and run: `localStorage.getItem('blotter_users')`
→ Never cleared browser data?

### Tests failing
→ Run `storage.getRecords()` in console to verify data exists
→ Check browser console for error messages
→ Try resetting demo data
